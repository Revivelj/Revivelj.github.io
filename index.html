01 · ROBOTICS / REINFORCEMENT LEARNING 返回概览 ↑

四足机器人强化学习运动控制

面向四足机器人在复杂地形下的自主运动控制问题， 基于深度强化学习构建从仿真训练到实际机器人部署的运动控制流程。

项目背景

传统四足机器人控制方法通常依赖精确建模和人工设计的运动规划器， 在复杂地形和模型不确定条件下存在适应性不足的问题。 本项目采用深度强化学习方法学习机器人运动策略， 提高机器人对不同运动状态和环境条件的适应能力。

主要工作

  • 构建四足机器人仿真训练环境
  • 设计基于 PPO 的运动控制策略
  • 完成观测空间、动作空间与奖励函数设计
  • 开展策略训练、运动测试与部署验证
Python PyTorch PPO Isaac Gym Quadruped Robot
02 · UAV / COMPUTER VISION / CONTROL 返回概览 ↑

基于视觉引导与模型预测控制的无人机自主抓取系统

面向复杂环境下的无人机自主抓取任务， 融合视觉感知、自主规划、模型预测控制和干扰估计， 实现从目标搜索到抓取运输的完整任务流程。

项目背景

本项目针对无人机执行自主抓取任务时存在的目标定位误差、 抓取后负载变化以及外部风扰等问题，设计了一套基于视觉引导 与模型预测控制的自主抓取系统。系统在 PX4 Offboard 模式下， 无需人工遥控即可完成目标搜索、识别定位、接近抓取、 抓取确认、运输和释放。

主要工作

  • 基于 YOLOv8 实现目标检测与三维定位
  • 设计视觉引导路径规划和有限状态机
  • 开发基于 NMPC 的轨迹跟踪控制器
  • 集成 EKF / FR-MHE 干扰估计与补偿
  • 通过压力传感器实现抓取状态判断
  • 完成 ROS、Gazebo、PX4 系统集成
NMPC Objective $$ J = \sum_{k=0}^{N-1} \left\|x_k-x_k^{ref}\right\|_Q^2 + \left\|u_k\right\|_R^2 + \left\|x_N-x_N^{ref}\right\|_P^2 $$
Disturbance Compensation $$ u = u_{\mathrm{NMPC}} - \hat{d} $$

03 · AI ENGINEERING / MODEL DEPLOYMENT 返回概览 ↑

深度学习模型部署与推理优化

面向深度学习模型在边缘计算设备上的部署需求， 开展模型转换、推理优化、性能测试与部署适配工作。

项目背景

深度学习模型在实际设备部署时通常受到计算资源、 内存占用和推理延迟等因素限制。 本项目围绕模型从训练框架到实际推理平台的转换流程， 分析模型精度与推理性能之间的关系。

主要工作

  • 完成 PyTorch 模型导出与格式转换
  • 搭建 ONNX 模型推理流程
  • 开展模型精度与推理速度测试
  • 进行边缘设备部署适配与性能分析
PyTorch ONNX CANN Model Optimization Edge Deployment
04 · SENSOR FUSION / PERCEPTION 返回概览 ↑

相机-雷达联合标定与多传感器融合

面向机器人环境感知任务，研究相机与雷达之间的空间关系估计、 外参标定和多传感器数据融合方法。

项目背景

单一传感器在复杂环境中容易受到视野、距离或环境条件的限制。 通过建立相机与雷达之间的空间变换关系， 可以将不同传感器的信息映射到统一坐标系， 为机器人环境感知提供更加完整的数据基础。

主要工作

  • 建立相机与雷达坐标系模型
  • 完成传感器外参标定
  • 分析标定误差及坐标转换误差
  • 实现多源感知数据的统一表达与融合
