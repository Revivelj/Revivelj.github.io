01 · ROBOTICS / REINFORCEMENT LEARNING 返回概览 ↑

四足机器人强化学习运动控制

面向复杂地形与动力学不确定条件下的四足机器人自主运动控制问题， 融合深度强化学习、时序残差预测与可达性安全评估， 构建从仿真训练、风险感知到实机部署的鲁棒运动控制系统。

项目背景

针对四足机器人在陌生地形、负载变化及模型失配条件下容易出现运动性能下降 甚至失稳的问题，本项目采用深度强化学习学习复杂环境下的运动策略， 并引入时序残差预测建模标称动力学与真实动力学之间的差异。 同时结合基于 Hamilton-Jacobi 可达性理论的 Reach-Avoid 值网络， 对机器人潜在碰撞与失稳风险进行实时评估，实现敏捷策略与恢复策略之间的安全切换， 提升机器人在复杂环境中的运动鲁棒性与安全性。

主要工作

  • 基于 Isaac Gym 搭建四足机器人大规模并行强化学习训练环境， 完成地形、摩擦系数、机器人质量、质心偏移、执行器时延及传感器噪声等物理参数与感知噪声的域随机化设计，并实现多环境独立重置， 提升策略对复杂环境和动力学变化的适应能力。
  • 设计基于 PPO 的四足机器人运动控制策略， 完成包括本体感知、地形射线、目标运动指令及历史动作在内的观测空间构建， 设计融合位置追踪、航向跟踪、碰撞惩罚、停滞惩罚和动作平滑约束的奖励函数， 输出 12 维关节目标角度并通过固定增益 PD 控制器实现底层力矩控制。
  • 构建基于时序残差预测的动力学补偿模块， 利用历史残差序列刻画标称模型与真实运动状态之间的偏差， 通过 MLP 预测未来残差，并提取历史及未来残差特征， 将其注入策略观测空间以增强策略对动力学漂移的预测能力。
  • 设计基于 Hamilton-Jacobi 可达性理论的 Reach-Avoid 值网络， 通过离线采集敏捷策略运行轨迹并学习可达性值函数， 实时评估机器人在当前状态下的碰撞与失稳风险， 根据安全阈值动态切换敏捷策略与恢复策略，实现面向安全约束的双策略控制框架。
  • 开展 Sim-to-Real 部署与实机验证， 针对深度图射线预测误差、状态数据传输不稳定、PointLIO 状态更新间隔以及残差分布差异等问题， 采用监督重训练、数据复用、定时器缓存和噪声增强等方法进行系统改进， 并通过消融实验分析历史残差、未来残差及域随机化对运动性能的影响。

基于视觉引导与模型预测控制的无人机自主抓取系统

面向复杂环境下的无人机自主抓取任务， 融合视觉感知、自主规划、模型预测控制和干扰估计， 实现从目标搜索到抓取运输的完整任务流程。

无人机第三视角

展示无人机完成目标检测、三维定位、 干扰估计及自主路径规划的初步仿真流程程。

展示无人机识别和检测功能。

项目背景

本项目针对无人机执行自主抓取任务时存在的目标定位误差、 抓取后负载变化以及外部风扰等问题，设计了一套基于视觉引导 与模型预测控制的自主抓取系统。系统在 PX4 Offboard 模式下， 无需人工遥控即可完成目标搜索、识别定位、接近抓取、 抓取确认、运输和释放。

主要工作

  • 搭建基于 ROS1 / Gazebo / PX4 Offboard 的无人机自主抓取仿真环境， 完成飞控、深度相机、气泵、电磁阀及压力传感器等软硬件模块集成， 构建目标搜索、接近、抓取、运输与释放的全流程任务场景。
  • 部署并微调 YOLOv8n 目标检测模型，融合相机深度信息， 通过像素坐标反投影、坐标系变换及滤波处理实现目标三维位置与位姿估计， 为无人机自主接近和抓取提供视觉观测。
  • 设计基于有限状态机的视觉引导路径规划方法， 实现目标搜索、位置对准、姿态调整、抓取确认及目标运输等任务状态切换， 并利用压力传感器检测气路压力变化判断吸附是否成功，支持失败重试。
  • 建立四旋翼无人机非线性运动模型，基于 acados 开发 NMPC 轨迹跟踪控制器， 将推力与姿态控制指令纳入滚动优化过程，显式处理推力饱和、 姿态角和飞行区域等约束，实现复杂任务过程中的实时轨迹跟踪。

  • 集成 EKF 与 FR-MHE 两种干扰估计器，将负载突变和风扰引起的等效加速度干扰 通过前馈补偿引入 NMPC 预测模型，并开展多算法对比验证， 使轨迹跟踪 RMSE 降低约 30%，提升系统抗干扰能力与鲁棒性。

昇腾 CANN 平台模型图与算子级推理优化

面向昇腾 CANN 平台上的视觉感知与 Transformer 模型部署需求， 从计算图结构、算子执行路径和数据内存布局三个层面开展推理性能优化， 通过图级冗余消除、算子融合及硬件友好的数据排布设计， 在保持模型计算结果与特征响应一致的前提下降低推理时延和内存访问开销。

项目背景

深度学习模型经 ATC 转换为昇腾 OM 格式后， 仍可能存在计算图冗余、算子组合不合理以及中间张量频繁搬运等问题。 本项目围绕自动驾驶视觉感知模型与 Transformer 模型， 分别从计算图级别和底层算子级别开展性能调优。 一方面通过删除无效节点、等价融合等方式减少冗余计算； 另一方面针对多头注意力中的矩阵乘法与数据排布转换， 优化计算结果的搬出路径和内存布局，降低额外访存与 Kernel 调度开销。

主要工作

  • 基于昇腾 CANN / ATC 完成模型转换、算子分析与性能 profiling， 针对 IPM-PID 视觉感知模型检查计算图中的冗余分支、 恒等映射及无效计算节点，并进行图级裁剪与结构清理。
  • 对模型中的 Conv-BN 等连续算子进行等价变换与融合， 在保证模型输出和关键中间层特征响应一致的前提下， 减少不必要的算子执行与中间张量传递，优化整体计算图执行路径。
  • 针对 Transformer 多头注意力中的 QKV 映射与数据排布转换问题， 分析 MatMul 输出布局与下游所需 [B, H, S, D] 布局之间的重排开销， 设计 MatMul-Transpose 融合方案，避免中间 [B, S, N] 张量的额外写回、读取和再次写回。
  • 基于 MatMulImpl 与 Datacopyout callback 实现计算与数据搬出协同， 利用 Fixpipe 的 NZ-ND 转换能力直接生成目标布局， 并结合多核任务切分和计算-搬出流水线重叠， 降低数据搬运、Kernel 调度及下游算子等待开销。
  • 搭建优化前后的精度对齐与性能评估流程， 对比端到端输出、关键中间层特征、GM 访存行为及 Kernel 数量， 验证图优化和算子重构的计算等价性， 使 IPM-PID 推理时延降低约 6.5%， Transformer 内存访问开销降低约 60%。

Transformer 混合精度量化与模型压缩

面向 Transformer 模型在昇腾平台上的高效部署需求， 设计融合激活校准、通道级权重量化与逐层敏感度回退的混合精度量化方案， 在保持模型精度的同时降低模型存储与计算开销。

项目背景

Transformer 模型通常具有较大的参数规模和较高的计算开销， 直接采用低比特量化容易受到激活分布、异常值和不同层敏感度差异的影响， 导致模型精度下降。本项目针对 Transformer 模型设计混合精度量化流程， 在模型压缩率、推理效率和任务精度之间进行平衡。

主要工作

  • 设计面向 Transformer 的混合精度量化方案， 融合 IFMR 激活校准、per-channel 权重量化及自适应对称/非对称量化策略， 根据不同层的数值分布选择合适的量化方式。
  • 建立逐层量化敏感度分析流程， 通过对关键层进行精度评估并结合二分回退策略， 对高敏感度层保留更高精度，降低整体量化误差累积。
  • 搭建量化模型的端到端精度验证流程， 对比量化前后模型输出及任务指标， 在 210×13 输出规模验证中实现零精度损失。
  • 在满足精度约束的前提下优化模型位宽分配， 将量化模型压缩至原始模型大小的约 33%， 降低模型存储和部署成本。

基于 Agent Skill 的昇腾模型转换自动化工具链

面向昇腾模型部署流程中模型解析、配置生成与 OM 转换等重复性操作， 设计基于 Agent Skill 的自动化编排工具链， 实现从 ONNX 模型到目标芯片 OM 文件的端到端自动转换与平台适配。

项目背景

昇腾模型部署通常需要依次完成模型结构解析、输入输出配置、 ATC 参数设置、目标芯片适配及 OM 文件生成等操作。 不同模型和芯片平台之间存在配置差异，人工执行过程繁琐且容易出现参数错误。 本项目将模型转换流程封装为可调用的 Agent Skill， 通过工具链编排实现模型部署过程的自动化和标准化。

主要工作

  • 设计端到端 ONNX → OM 模型转换 Skill， 将模型解析、输入输出信息提取、配置文件生成及 ATC 转换等步骤 封装为可被 Agent 调用的工具能力。
  • 构建模型转换流程的自动化编排逻辑， 根据模型结构和用户输入自动生成转换配置， 减少人工填写动态尺寸、输入格式及数据类型等参数的工作量。
  • 针对 Ascend 310、Ascend 910 等不同目标芯片设计参数适配机制， 根据目标硬件自动匹配对应的 ATC 编译参数和转换配置。
  • 打通模型仓库、模型解析工具、配置生成模块与 OM 转换工具链， 实现从模型文件输入到目标平台 OM 文件输出的一键式生成流程。
