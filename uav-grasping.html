UAV · MOTION PLANNING · CONTROL

无人机自主抓取与视觉伺服控制

面向无人机平台的目标感知、位姿估计、 轨迹规划与自主抓取控制系统。

UAV Computer Vision Motion Planning Visual Servoing Control

项目概述

本项目研究无人机在动态或半结构化环境中的自主抓取任务， 通过视觉感知获取目标位置与姿态信息， 结合运动规划和控制算法实现无人机末端执行器对目标的自主接近与抓取。

系统涵盖图像处理、目标检测、坐标系转换、 轨迹生成、姿态控制和抓取动作执行等模块。

项目目标

  • 实现视觉目标定位
  • 完成无人机末端位姿控制
  • 规划平滑安全的飞行轨迹
  • 实现目标自主抓取

使用技术

  • Python / C++
  • Computer Vision
  • Pose Estimation
  • Motion Planning
  • PID / Position Control

核心工作

目标视觉检测

对相机采集图像进行目标识别和位置提取， 为后续抓取任务提供视觉输入。

坐标系转换

建立相机坐标系、机体坐标系、 世界坐标系和末端执行器坐标系之间的转换关系。

轨迹规划

根据目标位置生成平滑的空间运动轨迹， 避免运动过程中的剧烈姿态变化。

闭环控制

根据视觉反馈实时修正无人机位置和姿态， 提高目标接近和抓取过程中的定位精度。
