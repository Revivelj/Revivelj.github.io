SENSOR FUSION · COMPUTER VISION

相机-雷达联合标定与多传感器融合

研究相机与雷达之间的空间几何关系， 完成传感器外参标定、坐标系转换以及多源感知数据融合。

Camera LiDAR Calibration Point Cloud Sensor Fusion

项目概述

本项目面向机器人和智能系统中的多传感器感知任务， 研究相机与雷达之间的空间坐标关系， 通过联合标定将不同传感器采集的数据映射到统一坐标系。

通过建立准确的外参变换关系， 实现图像信息与三维点云信息的融合， 为目标检测、定位和环境感知提供基础。

项目目标

  • 建立相机和雷达坐标变换关系
  • 估计传感器之间的旋转和平移参数
  • 实现图像与点云空间对齐
  • 提升多传感器融合精度

使用技术

  • OpenCV
  • Point Cloud Processing
  • Coordinate Transformation
  • Camera Calibration
  • Python / C++

数据处理流程

Camera Data RGB Image
→
LiDAR Data 3D Point Cloud
→
Extrinsic Calibration Rotation / Translation
→
Coordinate Transform Common Coordinate
→
Sensor Fusion Aligned Data

核心工作

相机内参标定

获取相机焦距、主点和畸变参数， 建立图像像素坐标与相机坐标之间的关系。

雷达点云处理

对原始点云进行滤波、降采样和噪声处理， 提升后续标定计算的稳定性。

外参估计

计算相机与雷达之间的旋转矩阵和平移向量， 建立两个传感器之间的空间映射关系。

融合结果验证

将雷达点云投影到图像平面， 通过可视化方式验证标定结果的准确性。

项目成果

坐标对齐 实现相机图像与雷达点云的空间对齐。
标定精度 通过可视化投影验证外参估计效果。
融合应用 为机器人环境感知和目标定位提供数据基础。
