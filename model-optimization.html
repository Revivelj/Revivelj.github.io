AI ENGINEERING · MODEL DEPLOYMENT

深度学习模型压缩与边缘部署优化

面向嵌入式和边缘计算平台的深度学习模型转换、 量化、推理优化与工程部署。

PyTorch ONNX CANN Quantization Edge AI

项目概述

本项目面向资源受限的边缘计算设备， 研究如何将深度学习模型从训练框架转换到实际部署平台， 并通过模型简化、算子优化、精度转换和推理加速降低计算开销。

项目重点关注模型在真实硬件平台上的运行效率， 包括推理延迟、显存占用、模型精度以及部署稳定性。

项目目标

  • 降低模型推理延迟
  • 减少模型计算量和存储占用
  • 完成训练模型到部署模型的转换
  • 保持模型精度稳定

使用技术

  • PyTorch
  • ONNX
  • TensorRT / CANN
  • FP16 / INT8 Quantization
  • Python / C++

部署流程

Training Model PyTorch
→
Model Export ONNX
→
Graph Optimization Operator Fusion
→
Quantization FP16 / INT8
→
Edge Deployment Real Hardware

核心工作

模型转换

将 PyTorch 模型导出为 ONNX 格式， 检查算子兼容性并解决转换过程中的算子问题。

计算图优化

通过算子融合、冗余节点消除和计算图简化， 降低模型执行过程中的额外开销。

低精度推理

使用 FP16 或 INT8 进行推理加速， 在精度和计算效率之间进行平衡。

性能分析

对模型推理延迟、内存占用、吞吐率和精度进行测试， 分析实际部署瓶颈。

项目成果

推理加速 通过模型优化降低边缘设备上的推理时间。
模型压缩 减少模型参数量、计算量和存储空间。
工程部署 完成模型从训练环境到实际硬件平台的部署流程。
